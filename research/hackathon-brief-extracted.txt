HACKATHON TASK
Web-Based 3D Furniture Modelling System
Challenge Theme
Design and Develop a SketchUp-Like 3D Modelling Application for Furniture & Interior Design
Objective
Develop a browser-based 3D modelling application that allows users to manually create furniture and interior models using tools similar to SketchUp.
The system should allow designers, carpenters, interior professionals and end users to create 3D furniture models interactively using basic drawing tools, exact dimensions, extrusion, movement, rotation, snapping and material application.
The application should be developed primarily using the MERN Stack, with a suitable WebGL-based 3D framework such as Three.js / React Three Fiber for the 3D modelling engine.
The focus of this hackathon is the 3D modelling and editing experience.
Existing cut-list calculation logic can later be integrated with the resulting 3D geometry.

1. PROBLEM STATEMENT
Most professional 3D modelling applications require specialized desktop software and significant training.
Furniture manufacturers and carpenters often require only a smaller subset of those features, such as:
Drawing panels
Creating boxes
Entering exact dimensions
Moving objects
Rotating objects
Copying objects
Snapping components
Creating cabinets
Creating shelves
Creating drawers
Applying materials
Viewing the model from different angles
Generating accurate geometry
The challenge is to develop a lightweight, browser-based 3D furniture modeller that provides these capabilities through an easy-to-use interface.

    \

The user should be able to draw a rectangular surface.
Example:

entered before drawing, or

4.4 Push/Pull Tool

38. FINAL DELIVERABLE
The expected hackathon outcome is a functional prototype of a:
Browser-Based 3D Furniture CAD / Modelling Platform
capable of providing a simplified SketchUp-style modelling experience specifically optimized for furniture and interior design.
The prototype should prove that users can create dimensionally accurate furniture models inside a web browser without depending on desktop CAD software.
The architecture should also make it possible to integrate the application's geometry with future modules such as:
Cut List → BOM → Material Estimation → Pricing → Quotation → Manufacturing.
